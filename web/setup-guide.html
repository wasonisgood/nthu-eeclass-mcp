依據安全授權規範，使用 Claude Desktop MCP 前需完成瀏覽器擴充功能就緒與課程身份掃描。
1

步驟一：取得擴充功能目錄

擴充套件已在您的本機電腦就緒。您可以直接在檔案總管開啟目錄，或下載 ZIP 壓縮檔：

C:\Users\user\Downloads\式\nthu-eeclass-copilot
下載擴充套件 (ZIP)
2

步驟二：載入未打包擴充功能至 Google Chrome

請依照下列說明將外掛載入至 Chrome：

  1. 開啟 Google Chrome，於網址列輸入 chrome://extensions/ 並按下 Enter
  2. 開啟右上角「開發人員模式」開關
  3. 點擊左上角「載入未打包項目」，選擇上述專案目錄完成載入
3

步驟三：外掛連線檢測與啟動全螢幕設定精靈

載入完成後，外掛背景服務將自動與本機 MCP 橋接器建立即時連線。系統將自動啟動擴充功能內建的全螢幕設定精靈。
